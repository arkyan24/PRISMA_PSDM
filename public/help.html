AKTIF DI CLOUD

Saat ini aplikasi PRISMA Anda secara bawaan menggunakan Mesin Leksikon Node.js. Pendekatan ini sengaja dibuat agar aplikasi:

  • Sangat Ringan & Cepat: Analisis sentimen selesai dalam waktu < 5 milidetik per teks berita.
  • 100% Kompatibel dengan Vercel: Beban file PyTorch di server cloud adalah 0 MB, sehingga bebas dari error batas ukuran Vercel (LAMBDA_SIZE_EXCEEDED).
  • Siap Pakai: Anda tidak diwajibkan menginstal Python atau mengunduh model berukuran gigabyte di laptop Anda.
Ingin Akurasi Lebih Baik?
Mesin Node.js bekerja menggunakan kamus kata kunci dan aturan tata bahasa. Jika Anda ingin sistem memiliki pemahaman konteks yang mendalam (Contextual Understanding), mendeteksi sarkasme, sentimen ganda, atau bahasa gaul media sosial yang kompleks, Anda bisa mengaktifkan Model Deep Learning IndoBERT (PyTorch) yang berjalan di memori perangkat komputer/laptop Anda sendiri!

Panduan Lengkap Setup PyTorch IndoBERT di Komputer Anda

Ikuti 5 langkah mudah berikut untuk menjalankan AI canggih di komputer lokal Anda

OPSIONAL / AKURASI TINGGI
1
Periksa Instalasi Python di Laptop Anda
Pastikan komputer Anda sudah terinstal Python versi 3.9, 3.10, 3.11, atau 3.12. Buka terminal (Command Prompt / PowerShell di Windows, atau Terminal di macOS/Linux) dan jalankan:
python --version
Jika Python belum terpasang, unduh secara gratis di situs resmi python.org (pastikan centang opsi "Add Python to PATH").
2
Buka Terminal di Folder PRISMA dan Buat Virtual Environment
Masuk ke direktori folder proyek ini, lalu buat lingkungan Python terisolasi agar paket tidak tercampur:
python -m venv venv
Aktifkan virtual environment tersebut:
.\venv\Scripts\activate
(Untuk pengguna macOS / Linux, jalankan: source venv/bin/activate)
3
Instal Dependensi PyTorch & Transformers
Instal paket FastAPI, PyTorch, dan Hugging Face Transformers yang telah disiapkan di file sentiment_service/requirements.txt:
pip install -r sentiment_service/requirements.txt
💡 Memiliki Kartu Grafis NVIDIA (GPU)? Anda dapat mengaktifkan akselerasi CUDA agar proses inferensi lebih cepat dengan menjalankan: pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
4
Jalankan Service PyTorch IndoBERT
Nyalakan microservice Python lokal dengan perintah berikut:
python sentiment_service/app.py
Saat pertama kali dijalankan, sistem akan mengunduh bobot model mdhugol/indonesia-bert-sentiment-classification (sekitar 400 MB) dan menyimpannya di memori/cache lokal. Terminal akan menampilkan pesan:
✓ IndoBERT Sentiment Service ready on http://127.0.0.1:8000
5
Hubungkan di Halaman Pengaturan Web PRISMA
Buka menu Pengaturan (/settings) di dashboard PRISMA:
  1. Gulir ke seksi "Mesin Analisis Sentimen NLP".
  2. Pilih Mode: 🟢 Otomatis / Hybrid (atau 🧠 Lokal PyTorch).
  3. Pastikan URL Service terisi: http://127.0.0.1:8000.
  4. Klik tombol "Uji Koneksi". Banner akan berubah menjadi hijau bertuliskan "Terhubung ke PyTorch IndoBERT! (Device: CPU/CUDA)".
  5. Klik "Simpan Pengaturan NLP". Selesai! Semua pemindaian berita selanjutnya akan dianalisis oleh kecerdasan IndoBERT.

Bagaimana Jika Website Dideploy di Hosting Vercel (Online)?

Opsi menghubungkan laptop lokal Anda ke website online di Vercel

Jika website PRISMA Anda telah dihosting online di Vercel (misalnya https://prisma-muhammadiyah.vercel.app), Anda memiliki 2 pilihan fleksibel:

Pilihan A: Biarkan Mode Node.js (Paling Praktis)

Anda tidak perlu membuka terminal ataupun menyalakan laptop. Vercel akan otomatis menjalankan analisis leksikon Node.js di awan 24 jam sehari secara gratis dan tanpa kuota server.

Pilihan B: Hubungkan Laptop via Tunnel Gratis (ngrok)

Jika ingin akurasi IndoBERT saat website online, buat tunnel HTTPS gratis dari laptop Anda:

ngrok http 8000
Salin URL https://xxxx.ngrok-free.app yang muncul, lalu tempelkan ke menu Pengaturan > URL Service di web Vercel Anda.

Toleransi Otomatis (Zero-Downtime):
Jika laptop Anda dimatikan atau koneksi ngrok terputus, sistem di Vercel tidak akan pernah error. Sistem akan langsung secara otomatis kembali ke mesin Node.js sehingga proses monitoring berita tetap berjalan lancar!

Pertanyaan Sering Diajukan (FAQ)

Informasi tambahan seputar pengelolaan sistem dan troubleshooting

Q: Apakah saya wajib menjalankan service Python setiap hari?
Tidak. Service Python bersifat 100% opsional. Jika Anda tidak menyalakannya, mesin leksikon Node.js tetap bekerja melakukan pemindaian berita dan klasifikasi sentimen secara normal.
Q: Mengapa Vercel menolak file PyTorch sebelumnya?
Library PyTorch dan bobot model AI membutuhkan ruang hingga 4–5 GB. Vercel membatasi fungsi serverless maksimal 500 MB. Dengan arsitektur saat ini di mana PyTorch berada di perangkat pengguna, deploy ke Vercel dijamin 100% lolos dan ringan.
Q: Port 8000 bentrok atau sudah dipakai aplikasi lain, apa solusinya?
Anda bisa menjalankan service di port lain (misalnya 8005) dengan perintah uvicorn app:app --port 8005 di folder sentiment_service, lalu ganti URL di halaman Pengaturan menjadi http://127.0.0.1:8005.
